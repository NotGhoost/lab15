# Лабораторная работа 10 — вариант 18

Интерфейсы Workable и Teachable, три врача и два учителя.

## Открытие в IntelliJ IDEA
1. Распакуйте архив. В IntelliJ IDEA выберите **File → Open** и откройте папку этой лабораторной с файлом `pom.xml` (или сам `pom.xml` → **Open as Project**).
2. Подтвердите доверие к проекту и дождитесь импорта Maven. При необходимости в **File → Project Structure → Project** выберите JDK 8 или новее.
3. Откройте `src/main/java/Main.java` и нажмите зелёный треугольник возле метода `main`. Программы с вводом ожидают данные в окне Run.

## Запуск в терминале
Из папки с `pom.xml` выполните `mvn compile exec:java`. При первом запуске потребуется интернет для загрузки Maven-плагинов. Каждую лабораторную импортируйте отдельно: в проектах есть одноимённые классы. Каждый класс находится в собственном файле.
