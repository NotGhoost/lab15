# Лабораторные работы 1–14

Четырнадцать независимых Maven-проектов, вариант 18 (для ЛР 4 в методичке отдельные варианты не предусмотрены). В каждом есть `pom.xml`, исходники находятся в `src/main/java`, каждый класс — в отдельном файле.

Распакуйте архив. В IntelliJ IDEA выберите **File → Open** и откройте папку нужной лабораторной или её `pom.xml` как проект. Дождитесь импорта Maven, выберите JDK 8 или новее, откройте `Main.java` и запустите метод `main`. Подробности — в README каждой лабораторной.

Открывайте лабораторные по отдельности: в них есть классы с одинаковыми именами. При первом импорте потребуется интернет для загрузки Maven-плагинов. Для ЛР 4 программа запросит ваше имя. В ЛР 14 пример текста мечты можно заменить на свой в `Task1.java`.
